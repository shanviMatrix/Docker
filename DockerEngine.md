#Docker Engine
1. Hypervisors create different virtual machines.
2. The Docker engine will provide all the necessary requirements of an operating system (the bare minimum).
3. Not that heavy.
4. It creates a seperate network, isolated machine or RAM. (Enough to run your machine).
5. Dosen't require having a guest operating system.
6. Faster than a virtual machine. (spins a machine hardly in minutes).
